# Anyloc

Рекламный лендинг Anyloc: возможности сервиса, интерактивные примеры интерфейса и объёмная NFC-табличка во вступительной сцене. Прокрутка убирает логотип с крупного плана обратной стороны, отдаляет камеру и разворачивает табличку лицом к зрителю. Затем начинается содержание о сервисе.

Используется исходный логотип Anyloc. Палитра — холодный серый, графит и приглушённый синий. Демонстрационные данные интерфейса условные; сайт не подключён к рабочей базе сервиса.

## Файлы

- `dist/index.html` — содержимое страницы.
- `dist/style.css` — оформление и адаптивная раскладка.
- `dist/main.js` — вкладки, Three.js-сцена и движение таблички.
- `dist/assets/` — оригинальные версии логотипа, архитектурный фон, favicon, локальные Three.js r170 и Lenis 1.3.26 с лицензиями MIT.
- `ASSET-NOTES.md` — происхождение фонового изображения и промпт генерации.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages.

Сборка и установка зависимостей не требуются. Все пути к локальным ресурсам относительные, поэтому сайт работает в подпапке GitHub Pages. Шрифт Manrope загружается из Google Fonts, резервный шрифт — Arial.

## Локальный запуск

Запустите любой статический HTTP-сервер с корнем в `dist`. Например, при установленном Python:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Для загрузки JavaScript-модуля следует использовать HTTP-сервер, а не открывать HTML через `file://`.

## Публикация

Измените файлы в `dist`, сделайте commit и push в `main`. Workflow проверит синтаксис JavaScript и опубликует папку `dist` через GitHub Actions. Также доступен ручной запуск во вкладке Actions. Источник Pages в Settings → Pages должен быть **GitHub Actions**.

Вступление занимает 3,4 высоты экрана на компьютере и 3 на телефоне. На компьютере Lenis сглаживает прокрутку всей страницы. Прокрутка и Three.js используют общий цикл кадров; поворот имеет мягкий разгон и торможение. Цикл останавливается, когда движение завершено, а также при скрытой вкладке. Якорные ссылки тоже перемещают страницу плавно.

Материал таблички передаёт мелкую фактуру, отражения окружения и освещение с холодным заполняющим и тёплым основным светом. Кромка и NFC-вставка имеют отдельные материалы. Мягкая тень появляется по мере отдаления камеры. Центральный логотип — компактный исходник `anyloc-sidebar-logo.png` из проекта, с пропорциями 2170:725 и без свечения.

При включённом уменьшении движения вступление занимает один экран, табличка сразу показана лицевой стороной и неподвижна. WebGL-сцена не перехватывает нажатия и прокрутку; при недоступности WebGL остаются окружение и оригинальный логотип.
